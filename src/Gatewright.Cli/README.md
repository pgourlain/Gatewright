# Gatewright.Cli

The `gatewright` command line tool: import OpenAPI, export/import configuration, validate, publish and roll back.

Part of [Gatewright](https://github.com/pgourlain/gatewright), an API Management and reverse proxy built on YARP for Kubernetes. Licensed under the [MIT License](https://github.com/pgourlain/gatewright/blob/main/LICENSE).
