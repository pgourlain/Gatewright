# Gatewright.Abstractions

Stable public contracts for Gatewright policies: `IGatewayPolicy`, `IPolicyInstance`, `GatewayContext`, `PolicyResult`. Reference this package to write policies without depending on the gateway itself.

Part of [Gatewright](https://github.com/pgourlain/gatewright), an API Management and reverse proxy built on YARP for Kubernetes. Licensed under the [MIT License](https://github.com/pgourlain/gatewright/blob/main/LICENSE).
