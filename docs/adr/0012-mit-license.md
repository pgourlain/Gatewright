# ADR 0012: Choice of the MIT license

- Status: Accepted
- Date: 2026-11-04

## Context

The project is meant to be open source with maximum adoption, including by companies embedding it in custom distributions.

## Decision

The project is licensed under MIT. Dependencies must use MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, MS-PL, 0BSD or Unlicense; GPL, LGPL, AGPL, SSPL, BSL, Commons Clause and non-commercial or missing licenses are forbidden. Contributions use the DCO (sign-off) instead of a CLA. The name and logo are protected through TRADEMARKS.md.

## Consequences

Low friction for contributors and users. License compliance is verified in CI and THIRD-PARTY-NOTICES.md is generated.
